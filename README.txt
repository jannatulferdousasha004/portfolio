YOUR PORTFOLIO FOLDER
=====================
index.html   -> the website (open it in a browser to preview)
images/      -> profile.jpg (your photo) and cover.jpg (cover photo), already added
files/       -> your CV PDF (already added)

BEFORE YOU PUBLISH
1. Open index.html in a text editor (VS Code) and find "EDIT THESE" near the bottom.
   Your email is set; optionally add phone, github and linkedin links.
   Empty ones are hidden automatically.
2. (Photos are already added; replace images/profile.jpg or cover.jpg to change them.)
3. To add a news item, add a line at the top of UPDATES in the same place.

PUBLISH ON VERCEL
Upload the files INSIDE this folder (index.html, images, files) to a new GitHub
repository, then import that repo at vercel.com and click Deploy.
